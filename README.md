# 台股細產業營收 YoY 動能追蹤系統

## 這是什麼

自動追蹤台股所有子產業的月營收年增率（YoY）變化，偵測景氣循環轉折訊號。

把上市櫃約 1,700 間公司依「細產業」分類（例如：PCB、光通訊、被動元件...），每月自動爬取營收、加總計算 YoY，然後產生三種訊號：

- **Top 5 動能排行** — 近 3 個月 YoY 平均最強的產業，景氣循環股優先
- **YoY 負翻正偵測** — 前月 YoY 為負、本月轉正，代表產業可能觸底回升
- **YoY 破百偵測** — 本月 YoY ≥ 100%，代表爆發性成長

結果自動推送到 Telegram。

## 為什麼做這個

台股有 50+ 個細分產業，每個月營收公告後要逐一追蹤 YoY 變化非常耗時。
這套系統把整個流程自動化，讓我能在每月 11 號營收公告完畢後，
一鍵掌握哪些產業正在加速成長、哪些剛從谷底翻正。

用途是輔助景氣循環選股 — 當某個產業的 YoY 開始加速，代表該產業的個股可能即將啟動。

## 系統架構

```
成分股細產業整理.xlsx          ← 自訂的產業分類表（哪些股票屬於哪個子產業）
         ↓
  MOPS 公開資訊觀測站          ← 爬取上市+上櫃月營收
         ↓
  按子產業加總 → 計算 YoY      ← pandas 資料處理
         ↓
  ┌─────────────────────┐
  │ Top 5 動能排行       │
  │ 負翻正偵測           │      ← 三種訊號
  │ YoY 破百偵測         │
  └─────────────────────┘
         ↓
    Telegram 推送               ← 自動通知
```

## 功能細節

### Top 5 動能排行榜
- 以近 3 個月 YoY 平均值排序
- 景氣循環股優先排序（鋼鐵、航運、面板、記憶體等）
- 入榜條件：最新月 YoY > 前月 YoY（仍在加速）
- 淘汰條件：連續 2 個月 YoY 下滑 → 踢出排行

### 景氣循環股分類
- 透過 `cyclical_industries.json` 管理景氣循環產業關鍵字
- 涵蓋：塑化、鋼鐵、航運、面板、記憶體、PCB、被動元件、營建、機械等
- 可自行新增/刪除關鍵字

### 資料快取
- 已爬取的月營收自動快取為 JSON
- 重複執行不會重複爬取，節省時間與避免被擋

## 使用方式

### 安裝套件
```bash
pip install requests openpyxl pandas beautifulsoup4 lxml
```

### 設定
1. 準備好「成分股細產業整理.xlsx」（自訂的產業分類表）
2. 在程式碼中填入你的 Telegram Bot Token 和 Chat ID
3. 執行：
```bash
python industry_yoy_monitor.py
```

建議每月 11 號後執行（等營收公告完畢）。

## 輸出範例

程式會自動推送類似以下的訊號到 Telegram：

```
📊 細產業 YoY 動能 Top 5 (2026-10)

🥇 光通訊 🔄 (12檔)
   YoY +87.3%  3M均 +65.2%
   +42.1 → +58.7 → +65.2 → +87.3

🥈 PCB-HDI 🔄 (8檔)
   YoY +45.6%  3M均 +38.9%
   +28.3 → +33.1 → +38.9 → +45.6

🔥 YoY 負翻正 (2個)
  ▸ 被動元件 🔄  -5.2% → +12.8%
  ▸ 散裝航運 🔄  -8.1% → +3.4%
```
